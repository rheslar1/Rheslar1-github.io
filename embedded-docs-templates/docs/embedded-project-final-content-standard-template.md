# Embedded Project Final Content Standard (Template)

This file is intended to be included (or referenced) by each embedded project repo.

## Required Final Content
(1) final design report
(2) pin/connector/register map
(3) build/flash/deploy runbook
(4) evidence readme + evidence bundle
(5) performance budget
(6) HIL validation report (if timing-sensitive)
(7) fault injection / failure mode tests
(8) CI artifacts and test transcript evidence

## Implementation Rule
- If target hardware evidence is not yet available, include host simulation evidence and mark target evidence as pending.
- Do not claim hardware validation until logs/screenshots/bench captures are present.
