# Requirements Traceability — BeagleBone AD8232 EKG ADC Driver

Scrub date: 2026-06-11

## 1) Requirements (R)
R1. Acquire ADC waveform from BeagleBone IIO for a selected AIN channel.

R2. Reconstruct AD8232-side millivolts via explicit divider-ratio scaling.

R3. Optional lead-off detection using LO+/LO- GPIO value files.

R4. Baseline removal + smoothing for reviewable waveform evidence.

R5. R-peak detection and heart-rate/HRV metric generation.

R6. Evidence artifacts produced as CSV/JSON and plotted SVG/PNG.

R7. Deterministic simulation mode to generate evidence without hardware.

R8. Safety boundary and non-clinical scope enforcement.
