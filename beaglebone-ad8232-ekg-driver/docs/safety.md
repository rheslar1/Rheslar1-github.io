# Safety Notes

- This is not a medical device.
- Do not connect a patient to unsafe, unisolated, or unreviewed hardware.
- BeagleBone analog inputs are not patient-isolated medical acquisition circuits.
- Keep AD8232 output within BeagleBone ADC limits.
- Treat lead-off values as hardware status indicators, not clinical conclusions.
- Use this project for software architecture, simulation, and lab evidence only.
