# Axe + Playwright CI (Rheslar1-github-io)

This repo uses Playwright tests to run axe-core accessibility checks and keyboard-only smoke tests.

## Commands
- Install deps: `npm ci`
- Run all checks locally: `npx playwright test`

## Notes
- Requires Playwright + axe integration deps:
  - `@playwright/test`
  - `axe-playwright`
