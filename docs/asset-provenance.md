# Asset Provenance

## Profile And Portfolio Assets

| Asset Type | Location | Provenance |
| --- | --- | --- |
| Profile photo | `public/assets/` | User-provided local portfolio asset. |
| Project diagrams | `public/assets/projects/` and project `docs/` folders | Generated from local diagrams, screenshots, or repository architecture documents. |
| GitHub previews | `https://opengraph.githubassets.com/...` | GitHub OpenGraph preview images for repository cards. |
| Generated screenshots | `docs/evidence/` | Captured from the local production build with headless Chrome. |
| Project simulations | `docs/project-simulations/` and `docs/evidence/project-simulations/` | Generated by `npm run simulate:projects` from local portfolio project data. |
| Neural seizure plots | `neural-seizure-ai-analysis/docs/evidence/` | Generated by the synthetic Python pipeline. |
| AD8232 waveform plot | `beaglebone-ad8232-ekg-driver/docs/evidence/` | Generated by the AD8232 simulator/plotter. |
| AD8232 schematic | `beaglebone-ad8232-ekg-driver/docs/schematics/` | Hand-authored SVG schematic rendered to PNG with headless Chrome. |

## Rules

- Keep generated evidence with a README that states command, date/context, and provenance.
- Do not represent synthetic or simulated evidence as live hardware or patient/building data.
- Prefer real screenshots and generated artifacts over decorative images.
- Add source, license, or ownership notes when externally sourced assets are introduced.
