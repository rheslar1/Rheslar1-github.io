## Capture Command

```bash
npm run build
python3 -m http.server 4173 --directory build
google-chrome --headless=new --no-sandbox --disable-gpu \
  --virtual-time-budget=5000 \
  --window-size=1440,1200 \
  --screenshot=docs/evidence/portfolio-home-desktop.png \
  'http://127.0.0.1:4173/'
```
