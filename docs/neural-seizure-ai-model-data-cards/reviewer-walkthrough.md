# Reviewer Walkthrough (Plots, CSV/JSON Reports, C Export, Timing Artifacts)

This walkthrough explains how a reviewer should interpret each artifact produced by the neural seizure research pipeline.

## 1. Evidence Location
Evidence artifacts are generated under:
- `neural-seizure-ai-analysis/docs/evidence/` (example)

All evidence artifacts generated by the CLI should be referenced in an evidence manifest.

## 2. Run Summary Artifact
### `demo-report.json`
Contains:
- config
- `teacher_metrics`, `student_metrics`, optional `fused_metrics`
- `distillation` fields: weights/bias/decision threshold
- `teacher_predictions`, `student_predictions`, `fused_predictions`
- `post_processing` outcomes
- `safety_case`
- `explainability` top features

Reviewer checks:
- verify metrics are consistent with label framing
- verify thresholds and safety flags

## 3. Feature Contract Artifacts
### `window-features.csv`
Contains one row per window with numeric columns listed in `artifact_schema.py`:
- avg_energy, HFO power, HFO ratios
- PAC proxy, wavelet energy/entropy
- connectivity measures

Reviewer checks:
- column presence and numeric validity
- distributions plausibility for synthetic data

### `bbb-ekg-features.csv` (if EKG enabled)
Contains:
- mean_mv, peak_to_peak_mv
- heart_rate_bpm, rr_std_ms, rmssd_ms
- signal_quality and autonomic stress proxies

Reviewer checks:
- signal_quality gating behavior in fusion

## 4. Plots (SVG Evidence)
Plots are generated by `plots.py`.

### `synthetic-neural-ekg-traces.svg`
Shows:
- synthetic neural trace
- auxiliary EKG/ECG context trace
- pre-ictal and ictal markers

### `feature-trajectories.svg`
Shows:
- feature curves used by the teacher ensemble and distilled student

### `biomarker-feature-curves.svg`
Shows:
- HFO ratio, PAC proxy, connectivity curve over time

### `risk-warning-timeline.svg`
Shows:
- teacher probability curve
- distilled student probability curve
- fused curve (if present)
- threshold line and warning markers

### `algorithm-coverage-map.svg`
Shows:
- conceptual coverage of the algorithm pipeline blocks

### `time-frequency-image-map.svg`
Shows:
- image representation heatmap derived from time-frequency windows

## 5. C Export Artifacts
### `distilled_student.h` / `distilled_student.c`
Reviewer checks:
- feature count matches `FEATURE_COUNT`
- weights and threshold are embedded
- sigmoid probability is bounded

Also verify export is consistent with Python `distillation` output.

## 6. Timing Evidence
### `hil-timing-report.json` / `hil-timing-report.md`
Reviewer checks:
- platform identity
- average inference latency (us)
- max observed latency (us)
- notes clarifying whether evidence is host-side vs embedded target-side

## 7. Calibration Evidence (planned package)
See `calibration-evidence.md`.

If calibration sweep artifacts exist, reviewer checks:
- confusion matrix at chosen threshold
- lead-time distribution for true positives
- false-alert analysis window list

## 8. Safety Case
### `safety_case` in `demo-report.json`
Reviewer checks:
- project boundary is research-only
- required gates are present
- hazard register items align with observed metric flags
