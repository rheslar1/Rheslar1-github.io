# EnergyBuildAI Embedded Systems Portfolio Workspace

This workspace contains the Rheslar portfolio, EnergyBuildAI dashboard, BMS/BEMS project presentation, and Embedded Systems project collection.

Primary app:
- React portfolio and dashboard in `src/`
- Project catalog data in `src/data/projects.js`
- Embedded Systems project definitions in `src/data/embeddedSystemsProjects.js`
- Generated local embedded project repos in `embedded-system-repos/`
